# Ranch Manager Elite

A lightweight offline ranch management dashboard built with vanilla HTML/CSS/JS.

## Features
- Animal tracking
- Inventory management
- Finance tracking
- LocalStorage persistence
- Mobile-friendly UI

## Deploy to GitHub Pages

1. Create a GitHub repo
2. Upload all files
3. Go to Settings → Pages
4. Set:
   - Branch: `main`
   - Folder: `/root`
5. Open your live URL
